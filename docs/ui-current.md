# 現状UI仕様

- 作成日: 2026-09-07
- 対象: 縦横配信・UI見直し後の現在の作業ツリー
- 目的: 現在の実装を共通認識にし、次のUI修正指示を部品単位で出せるようにする
- 根拠: Compose実装の静的確認。実機スクリーンショットからの採寸ではない
- 状態: 現状記録であり、採用したい最終デザインではない

振る舞いの正本は [spec.md](spec.md)。次期UIの検討内容は [ui-design.md](ui-design.md)、
参考アプリの調査結果は [ui-references.md](ui-references.md) に分ける。

## 1. 画面構成

画面は次の2画面と1つのボトムシートで構成する。

| ID | 画面 | 実装 | 概要 |
|----|------|------|------|
| S-01 | 配信画面 | `ui/StreamScreen.kt` | プレビュー、状態、即時操作、配信開始・停止 |
| S-02 | 設定画面 | `ui/SettingsScreen.kt` | 配信先、映像、権限・接続準備 |
| S-03 | カメラとレンズ | `CameraMenuSheet` | 前面カメラと背面レンズの選択 |

`ui/AppRoot.kt` がS-01とS-02を切り替える。画面方向の変更でActivityが再生成されても、
`showSettings`は`rememberSaveable`により保持する。

## 3. 配信画面 S-01

### 3.1 共通構造

配信画面はヘッダーと、その下のプレビュー・操作領域に分かれる。

```text
+--------------------------------------------------+
| H-01 状態・時間                                  |
| H-02 解像度 / FPS / RTMPまたは送信統計           |
|                         H-03 電池   H-04 設定     |
+--------------------------------------------------+
| P-01 プレビュー                 | C-01 操作パネル |
| P-02 配信方向ラベル             |                 |
| P-03 音量メーター               |                 |
| P-04 準備中表示                 |                 |
+--------------------------------------------------+
```

表示領域の幅が高さより大きい場合は横レイアウト、それ以外は縦レイアウトになる。

### 3.2 ヘッダー

| ID | 要素 | 現状の表示・動作 |
|----|------|------------------|
| H-01 | 状態バッジ | 接続済みは赤背景で`LIVE mm:ss`。それ以外は接続中・再接続中・失敗理由等を表示 |
| H-02 | 技術情報 | `720 x 1280 / 30 fps / RTMP`等。統計取得後はRTMPの代わりに送信統計を表示 |
| H-03 | 電池 | 残量%と、充電時は`充電中`を表示。最大幅88dp |
| H-04 | 設定 | 48dpの歯車ボタン。S-02を開く |

H-01/H-02は残り幅を使い、長い文は1行で省略する。電池情報は30秒ごとに更新する。

### 3.3 プレビュー

| ID | 要素 | 現状の表示・動作 |
|----|------|------------------|
| P-01 | カメラプレビュー | 黒背景の中央に送信映像と同じ比率で配置。枠線あり |
| P-02 | 配信方向ラベル | 左上に`縦配信 / 9:16`または`横配信 / 16:9` |
| P-03 | 音量メーター | 左下に縦10セグメント。下から緑5・黄3・赤2。ミュート時は消灯 |
| P-04 | 準備中表示 | 中央に`プレビュー準備中`。必須権限がなければ権限要求ボタンも表示 |

P-01の幅と高さは、利用可能領域に収まる最大サイズとして計算する。`AspectRatioMode.Adjust`も使用し、
送信フレーム全体を表示する方針で、画面を埋めるための切り抜きはしない。

### 3.4 縦レイアウト

縦レイアウトでは操作パネルをプレビューの下に置く。

```text
+----------------------------------+
| H-01 LIVE/状態       H-03   H-04 |
| H-02 解像度 / FPS / 統計         |
+----------------------------------+
|                                  |
|          P-01 プレビュー         |
|                                  |
+----------------------------------+
| C-02 配信方向                    |
| [縦 9:16]       [横 16:9]        |
| [C-03カメラ] [C-04ライト] [C-05マイク] |
| [        C-06 配信開始/停止       ] |
| C-07 状態詳細                    |
+----------------------------------+
```

- 操作パネルの最大高は、ヘッダーを除く領域の48%。
- 配信方向と3つのクイック操作は必要に応じてスクロールする。
- C-06はスクロール領域の外にあり、パネル下部に残る。

### 3.5 横レイアウト

横レイアウトでは操作パネルをプレビューの右に置く。

```text
+--------------------------------------------------+
| H-01 LIVE/状態 / H-02       H-03 電池  H-04 設定 |
+--------------------------------+-----------------+
|                                | C-02 配信方向   |
|                                | [縦] [横]       |
|       P-01 プレビュー          | C-03 カメラ     |
|                                | C-04 ライト     |
|                                | C-05 マイク     |
|                                | C-06 開始/停止  |
+--------------------------------+-----------------+
```

- 右パネル幅は全体の34%を基準に、180〜264dpに制限する。
- クイック操作は縦積みになり、アイコンの右にラベルを表示する。
- 操作項目はスクロールし、C-06は右パネル下部に残る。

### 3.6 操作パネル

| ID | 要素 | 現状の表示・動作 |
|----|------|------------------|
| C-01 | 操作パネル | Surface色の独立領域。12dp内側余白 |
| C-02 | 配信方向 | `縦 9:16`と`横 16:9`の2分割選択。配信処理中は無効 |
| C-03 | カメラ | `前面カメラ`または`背面・レンズ`。S-03を開く |
| C-04 | ライト | `ライトON/OFF`。前面カメラまたはプレビュー未準備時は無効 |
| C-05 | マイク | `マイクON`または`ミュート中`。ミュート中は赤系 |
| C-06 | 配信開始・停止 | 開始は緑、停止は赤。プレビュー未準備時は開始不可 |
| C-07 | 状態詳細 | 待機中・切断・LIVE以外を主ボタンの下に最大2行表示 |

C-02を変更すると設定を保存し、Activityを選択方向へ回転する。配信中はUIと処理の両方で変更を拒否する。

### 3.7 状態ごとの差分

| 状態 | H-01 | C-02 | C-06 | C-07 |
|------|------|------|------|------|
| 待機中 | `待機中` | 有効 | 緑・`配信を開始` | 非表示 |
| 接続中 | `接続中...` | 無効 | 赤・`配信を停止` | 接続中を表示 |
| LIVE | 赤・`LIVE mm:ss` | 無効 | 赤・`配信を停止` | 非表示 |
| 再接続中 | 再接続理由 | 無効 | 赤・`配信を停止` | 再接続理由を表示 |
| 失敗後 | 失敗理由 | 有効 | 緑・`配信を開始` | 失敗理由を表示 |
| 権限なし | P-04で案内 | 有効 | 開始不可 | 通常は非表示 |

## 4. カメラとレンズ S-03

配信画面のC-03から開くMaterial 3ボトムシート。

```text
+----------------------------------+
|          ドラッグハンドル        |
| カメラとレンズ                   |
| 前面 71°                    ( )  |
| 背面 26°                    ( )  |
| 背面 71°                    (o)  |
| 背面 97°                    ( )  |
+----------------------------------+
```

| ID | 要素 | 現状の表示・動作 |
|----|------|------------------|
| L-01 | タイトル | `カメラとレンズ` |
| L-02 | 前面 | 前面カメラ。取得できれば画角ラベルを付加 |
| L-03 | 背面レンズ | 利用可能な背面レンズを画角ラベル付きで列挙 |
| L-04 | 選択表示 | 右側のラジオボタンと太字 |

一覧は縦スクロール可能。背面レンズを列挙できない場合は、前面と`背面カメラ`の2択になる。

## 5. 設定画面 S-02

### 5.1 全体

```text
+------------------------------------------+
| [戻る] 配信設定                          |
|        変更は自動で保存されます          |
+------------------------------------------+
| 配信処理中の注意文                       |
|                                          |
| + S2-A 配信先 -------------------------+ |
| | URL                                  | |
| | ストリームキー              [表示]   | |
| | [Gateway] [自宅Station例]             | |
| +--------------------------------------+ |
|                                          |
| + S2-B 映像 ---------------------------+ |
| | [縦 9:16] [横 16:9]                  | |
| | 送信解像度                           | |
| | ビットレート値・スライダー           | |
| +--------------------------------------+ |
|                                          |
| + S2-C 権限と接続の準備 ---------------+ |
| | 権限確認                             | |
| | Gateway / 自宅Stationの説明          | |
| +--------------------------------------+ |
+------------------------------------------+
```

- 内容の最大幅は720dp。広い画面では中央寄せ。
- 画面全体は縦スクロール可能。
- ソフトキーボード表示時は`imePadding()`を適用する。
- 各セクションはSurface色、角丸18dpのカード。

### 5.2 ヘッダーと注意

| ID | 要素 | 現状の表示・動作 |
|----|------|------------------|
| S2-H01 | 戻る | 配信画面へ戻る。Androidの戻る操作でも同じ |
| S2-H02 | タイトル | `配信設定` |
| S2-H03 | 補足 | `変更は自動で保存されます` |
| S2-H04 | 配信中注意 | 配信処理中のみ、ビットレート以外は停止後に変更できる旨を表示 |

### 5.3 配信先カード S2-A

| ID | 要素 | 現状の表示・動作 |
|----|------|------------------|
| S2-A01 | URL | 1行入力、URI用キーボード。配信処理中は無効 |
| S2-A02 | ストリームキー | 1行入力。既定はマスク、目アイコンで表示切替。配信処理中は無効 |
| S2-A03 | Gateway | サーバーURLを既定Gatewayへ変更 |
| S2-A04 | 自宅Station例 | ローカルIP例を設定し、キー空欄なら`livestream`を設定 |

### 5.4 映像カード S2-B

| ID | 要素 | 現状の表示・動作 |
|----|------|------------------|
| S2-B01 | 配信方向 | C-02と同じ2分割選択。配信処理中は無効 |
| S2-B02 | 持ち方説明 | 選択に応じてスマホを縦または横に持つよう表示 |
| S2-B03 | 送信解像度 | 480p / 720p / 1080p。実際の出力寸法も併記 |
| S2-B04 | ビットレート値 | kbps単位で大きく表示 |
| S2-B05 | ビットレート | 800〜8000kbpsのスライダー。配信中も変更可 |
| S2-B06 | 固定情報 | H.264 + AAC、30fps、キーフレーム2秒を表示 |

### 5.5 権限と接続準備カード S2-C

| ID | 要素 | 現状の表示・動作 |
|----|------|------------------|
| S2-C01 | 権限確認 | カメラ・マイク・通知の権限要求を開始 |
| S2-C02 | 権限説明 | 通知は任意、カメラ・マイクは必須と表示 |
| S2-C03 | Gateway説明 | チャンネル作成、URLと4桁キー入力を案内 |
| S2-C04 | Station説明 | RTMP受信待ち後の配信開始を案内 |

## 6. 現状UIの情報優先度

現在の実装を、常時表示される情報量として整理すると次の通り。

| 優先度 | 常時または直ちに見えるもの |
|--------|----------------------------|
| 最優先 | 接続状態、経過時間、配信開始・停止 |
| 高 | プレビュー、配信方向、カメラ、マイク、ライト |
| 中 | 解像度、FPS、送信統計、電池残量、音量メーター |
| 低 | 接続先・画質・権限・PeerCast手順。設定画面内 |

現状は配信方向の選択が配信画面に常時あり、プレビューとは別の操作パネルが大きな領域を使う。
ここが「映像主体の配信アプリ」にするか、「設定を常に確認できる操作画面」にするかを決める主な設計点になる。

## 7. 修正指示の書き方

部品IDを使うと、実装前のやり取りを短くできる。

```text
- 縦レイアウトではC-02をメイン画面から外し、S2-B01だけにする。
- C-03〜C-05はプレビュー上の右端に丸アイコンで重ねる。
- C-06は下中央の円形ボタンにする。
- H-02の解像度とFPSは設定画面だけに移す。送信統計は残す。
- P-01は画面全体を使い、操作パネル用の固定領域を作らない。
```

修正内容は [ui-design.md](ui-design.md) に反映し、そこで合意してからコードへ実装する。
