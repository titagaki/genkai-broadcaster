# 参考アプリUI調査

- 調査日: 2026-09-07
- 目的: UIをそのまま複製せず、配信画面の情報階層と操作パターンを検討する
- 対象: Moblin、IRL Pro、Larix Broadcaster、iPhone Camera、Pixel Camera
- 出典: 公式サイト、公式GitHub、公式ストア、メーカー公式ヘルプ

掲載画像や説明はバージョン・OS・機種で変わる。確認できた事実と、本アプリ向けの設計上の解釈を分ける。
SRT、録画保存、ボンディング、コメント、シーン合成は本アプリの対象外であり、機能として模倣しない。

## 1. 比較概要

| アプリ | UIの中心 | 即時操作 | 詳細設定 | 本アプリで参考にする点 |
|--------|----------|----------|----------|------------------------|
| Moblin | 大きな映像と周辺オーバーレイ | 右端のクイック操作、レンズ・倍率、終了 | カテゴリ別 | 映像主体、周辺へ操作を寄せる構成 |
| IRL Pro | 横向きの監視・操作画面 | カメラ直接選択、音量、配信情報 | 右側パネルと設定画面 | レンズを明示選択、技術情報の見せ方 |
| Larix | プレビューと明確なBroadcast操作 | 配信、カメラ、ズーム等 | 接続先を階層設定 | 配信画面と接続設定の分離 |
| iPhone Camera | ビューファインダー | 大きな録画、倍率、カメラ切替 | OS設定・追加コントロール | 主操作の明確さ、プレビュー優先 |
| Pixel Camera | ビューファインダー | 録画、停止・一時停止、ズーム | Video Settings / More settings | 即時操作と画質設定の段階化 |

## 2. Moblin

### 確認できた内容

- 公式READMEは前後カメラ・背面レンズ、ズーム、マイク選択、ミュート、トーチを明記している。
- 公式README掲載画像では、横画面の大部分をカメラ映像が占める。
- 状態表示やコメント領域を映像上の周辺に置き、右端に2列の丸いクイックボタンを配置している。
- 歯車は右上、赤い`End`は右下にあり、レンズ・倍率の選択列も映像の右下に見える。
- 設定はカテゴリ別の階層構造。クイックボタンのページ・配置変更など高度なカスタマイズも持つ。
- 横向きは両方向に対応。公式READMEでは縦向きUIと映像方向に制約がある旨も記載されている。

### 本アプリへの示唆

- プレビューを画面の主役にし、操作は映像の端へ寄せる。
- 配信終了は他のクイック操作と視覚的に分離する。
- カメラ面とレンズ・倍率を区別して表示する。
- シーン、コメント、任意配置、クイックボタン編集は本アプリには持ち込まない。

## 3. IRL Pro

### 確認できた内容

- 公式サイトは、単一の反転ボタンではなく、前面・背面の利用可能なカメラを直接選ぶ方式を説明している。
- Google Play掲載画像の横画面では、周辺に操作と情報を寄せ、中央領域を空ける構成が確認できる。
- 右側に丸い操作群、左側に縦の音量メーター、下部にビットレート・FPS・経過時間等がある。
- 前面・背面の選択肢に画角を度数で示す掲載画像がある。
- 別の掲載画像では、`CAMERA / NETWORK / DISPLAY / OVERLAY`のカテゴリを持つパネルが右側に重なる。
- 公式サイトは配信中のビットレート調整とバッテリー表示を案内している。

### 注意

- 掲載画像の版は不明で、現在の通常撮影時に中央がどのように見えるかは断定しない。
- 経過時間付近の赤い四角は停止操作に見えるが、画像だけで厳密な動作までは確定しない。
- 縦向きの設定画面があることは、縦向き配信への対応を直接意味しない。

### 本アプリへの示唆

- 利用できるレンズを直接選べることは、単純な前後トグルより誤操作が少ない。
- 音量、回線、経過時間はプレビューを隠さない周辺情報として扱う。
- 多数のネットワーク・表示・オーバーレイ機能は持ち込まない。

### 出典

- [IRL Pro公式サイト](https://irlpro.app/)
- [IRL Pro公式Google Play](https://play.google.com/store/apps/details?id=app.irlpro.android)

## 4. Larix Broadcaster

### 確認できた内容

- 公式Android設定記事は、プレビュー画面の大きな赤い`Broadcast`ボタンと設定用歯車を説明している。
- 接続先は`Settings → Connections → New connection`で登録し、プレビューへ戻って配信を始める。
- Android版の公式機能一覧は、配信中の前後カメラ切替、ピンチズーム、フォーカス・露出・ホワイトバランス制御を挙げている。
- 縦・横、端末回転、常時縦・常時横のモードに対応すると説明している。
- Pause/Stand-byはサーバー接続を維持したまま送出映像を変更できる。プレビュー表示と実際の送出状態が同義ではない例になる。

### 注意

- Android設定記事は2015年公開であり、現在の正確な配置を示す資料としては古い。
- メーカーが追加カメラを外部アプリへ公開しない場合、純正カメラと同じレンズを利用できない。

### 本アプリへの示唆

- 接続先の編集は設定画面へ分離し、配信画面は開始・停止と状態確認へ集中させる。
- `プレビュー表示中`、`配信処理中`、`サーバー接続済み`を別状態として表現する。
- Pause、録画、多プロトコル等は対象外。

### 出典

- [Larix Android設定記事](https://blog.wmspanel.com/2015/08/larix-broadcaster-live-streaming-setup.html)
- [Larix Android機能一覧](https://softvelum.com/larix/android/)
- [Larix FAQ](https://softvelum.com/larix/faq/)
- [Pause / Stand-by公式解説](https://softvelum.com/2025/05/pause-standby-mute-enhancements-larix/)

## 5. スマホ標準カメラ

標準カメラは機種・OS・モードで異なり、共通の固定レイアウトはない。ここでは操作階層を参考にする。

### iPhone Camera

- Appleの動画ガイド掲載図では、録画ボタンが下中央、ビューアが左下、カメラ切替が右下、追加コントロールが右上、動画フォーマットが左上。
- 動画中のピンチズーム、機種ごとの倍率ボタン、倍率ボタン長押しからの細かな調整を案内している。
- 写真撮影では、被写体タップでフォーカス、露出調整、長押しでAE/AF Lockという、プレビューへの直接操作がある。

出典:

- [Apple: ビデオを撮影](https://support.apple.com/guide/iphone/record-videos-iph61f49e4bb/ios)
- [Apple: 構図を設定](https://support.apple.com/guide/iphone/set-up-your-shot-iph3dc593597/ios)

### Pixel Camera

- Googleのヘルプは、Videoへ切り替え、Recordで開始、Stopで停止する流れを説明する。Pause/再開は別操作。
- 解像度・FPS・手ぶれ補正はVideo Settings、一般設定はMore settingsという段階化がある。
- 対応機種では、通常のズームと`UW / W / T`によるレンズ直接選択を切り替えられる。
- 機種やモードにより、フォーカス・露出・シャッター速度・ISO等の利用範囲が異なる。

出典:

- [Google Pixel Camera: 動画を撮影](https://support.google.com/pixelcamera/answer/7064897?hl=en)
- [Google Pixel Camera: カメラ設定](https://support.google.com/pixelcamera/answer/2838995?hl=en)
- [Google Pixel Camera: レンズ・撮影調整](https://support.google.com/pixelcamera/answer/14106982?hl=en)

### 本アプリへの示唆

- 大きな主操作を置き、カメラ・倍率・フォーカス等の即時操作と、画質・接続先等の事前設定を分ける。
- 赤い録画ボタンをそのままRTMPのLIVE状態へ読み替えない。開始操作、接続中、接続済み、再接続中を区別する。
- 写真モード、ギャラリー、端末内録画は本アプリには不要。

## 6. 採用候補となる設計原則

以下は参考アプリの仕様ではなく、本アプリ向けの候補。

| ID | 原則 | 内容 |
|----|------|------|
| R-01 | 映像主体 | プレビューを最大化し、中央を常設パネルで塞がない |
| R-02 | 主操作を分離 | 配信開始・停止を、設定・ライト・ミュートから離して強調する |
| R-03 | 状態を分離 | 開始操作、接続中、LIVE、再接続中、停止を色と文言で区別する |
| R-04 | 即時操作を限定 | カメラ、レンズ、ミュート、ライト等、配信中に使うものだけ常設する |
| R-05 | 詳細設定を退避 | 接続先、解像度、方向、ビットレート等は設定画面を基本とする |
| R-06 | レンズを明示 | 前後トグルだけでなく、利用可能なレンズを直接選べるようにする |
| R-07 | 縦横を別設計 | 画面UIの向きと送信映像の向きを区別し、両方の配置を設計する |
| R-08 | 文字を併用 | 重要操作はアイコンだけにせず、意味または状態を短い文字で示す |

## 7. そのままコピーしないもの

- Moblinのシーン・ウィジェット・コメント・クイックボタン編集。
- IRL ProのSRTLA、ボンディング、詳細なネットワーク監視、コメント表示。
- Larixの多プロトコル、録画、Pause/Stand-by、詳細な映像制御。
- 標準カメラの写真モード、ギャラリー、端末内録画。
- `0.5x`等の固定倍率。外部アプリへ公開されるカメラは端末ごとに異なる。
