# JPNKN Vox 連携ガイド (コメント表示)

本アプリはコメントの取得を行わず、別アプリ [JPNKN Vox](https://github.com/titagaki/jpnkn-vox)
(jpnkn 掲示板・ツイキャス・Twitch のコメントを読み上げるアプリ) から受け取って配信映像に焼き込みます。
仕組みは [コメント表示設計](../engineering/comment-overlay.md) を参照。

## 手順

1. JPNKN Vox (コメント受け渡しに対応した版) をインストールし、取得先 (板 ID など) を登録しておく。
2. 本アプリの 設定 → **コメント** で `JPNKN Vox` を選ぶ (配信停止中のみ変更可)。
   一覧に出ない場合は JPNKN Vox のインストールと版を確認する。
3. JPNKN Vox 側で読み上げを開始する (トップバーのスイッチ)。本アプリは配信中だけ JPNKN Vox に接続する。
4. 配信を開始すると、受信したコメントが映像の右下 (設定で右上にも変更可、配信中でも可) に最新 5 件、10 秒ずつ表示される。プレビューにも同じものが映る。

## 状態表示

配信画面の情報表示 3 行目に接続状態が出る。

| 表示 | 意味 |
|------|------|
| `コメント: JPNKN Vox` | 接続済み。コメントが届けば映像に乗る |
| `コメント: JPNKN Vox に接続中` | bind 中、または JPNKN Vox が取得先へ再接続中・接続待ち |
| `コメント: JPNKN Vox が停止中` | JPNKN Vox の読み上げが開始されていない。JPNKN Vox 側で開始する |
| `コメント: JPNKN Vox の取得先でエラー` | JPNKN Vox 側の取得先 (板 ID 等) を確認する |
| `コメント: 提供アプリが見つかりません` | 設定した提供アプリがアンインストールされている |

## 注意

- JPNKN Vox の読み上げ音声 (TTS) はスピーカーから出ると本アプリのマイクに乗る。イヤホンを使うか、JPNKN Vox 側の音量を下げる。
- コメントの大きさ・秒数は現状固定 (設定なし)。位置は上下のみ選べる。
