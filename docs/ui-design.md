| 形 | 円形 / 角丸長方形 / その他 | 未定 |
| 位置 | 下中央 / 右下 / 右端 / その他 | 未定 |
| 開始色 | 赤 / 緑 / 白 / その他 | 未定 |
| 停止色 | 赤 / その他 | 未定 |
| ラベル | アイコンのみ / 文字併用 | 未定 |
| 停止確認 | なし / タップ確認 / 長押し | 未定 |

状態の意味は次を維持する。

- 開始ボタンを押した直後は`接続中`であり、まだLIVEではない。
- 接続成功後だけ`LIVE`と表示する。
- 再接続中はLIVE表示にしないが、停止操作は常に残す。
