## 1. 目標

- カメラプレビューは操作帯を除いた領域いっぱいに表示する。
- 配信情報・設定・音量メーターは、IRL ProやMoblinのようにプレビューの上へ重ねる。
- 操作 (カメラ・倍率、配信開始・停止、マイク) はスタジアム形の操作帯に1か所へまとめ、プレビューと重ねない。
  縦配信では下、横配信では右に置く。
- 常設要素は画面の上下・左右端へ寄せ、映像の中央を空ける。
- 詳細設定は別の設定画面、または必要時だけ開くオーバーレイとする。
- `待機中`・`LIVE`・`切断`を大きなステータスバッジでは表示しない。
- 配信開始・停止ボタンの色と状態で、配信処理中かどうかを判断できるようにする。
- 状態文は解像度・FPSと同じ小さな補助情報としてプレビューへ重ねる。
- 縦配信・横配信の切替は設定画面だけに置く。

## 2. 配信画面の方向性

候補は排他的ではない。例えば「Aを基本に、IRL Proのレンズ選択を採用」のように指定できる。

| 案 | 概要 | 長所 | 注意点 | 採否 |
|----|------|------|--------|------|
| A: Moblin寄り | 全面プレビューへ周辺操作を重ねる | 映像が大きい、配信中の視認性が高い | 操作と映像が重なる | 採用要素 |
| B: 標準カメラ寄り | 全面プレビュー＋下部の大きな主ボタン | 分かりやすい、主操作が明確 | 配信情報の置き場が必要 | 未定 |
| C: IRL Pro寄り | 全面プレビュー＋周辺の監視情報・レンズ操作 | 配信状態を詳しく見られる | 情報量が増えやすい | 基本方針 |
| D: パネル分離 | プレビューと操作パネルを分離 | 誤操作しにくく文字が読める | プレビューが小さい | 操作帯として部分採用 |

情報表示はA・Cのようにプレビューへ重ね、操作だけをDのように帯へ分離する。
帯は矩形パネルではなくスタジアム形にして、映像との境界を柔らかくする。

## 3. 縦画面ワイヤーフレーム

プレビューの下にスタジアム形の操作帯を置く。現在の実装位置を次に示す。

```text
+----------------------------------+
| D-H01 状態/解像度/FPS    D-C06設定|
| D-H02時間/D-H03統計/D-H04電池    |
|                                  |
|            D-P01                 |
|                                  |
| D-M01音量                        |
+----------------------------------+
| ( D-C02 BACK・1x  D-C01 ●  D-C03 ○ ) |  D-B01
+----------------------------------+

上の枠がD-P01のカメラプレビュー。情報表示・設定・音量はD-P01の上に重なり、
操作はD-B01にまとめる。
```

| ID | 要素 | 表示位置 | 常時表示 | 操作 | 決定 |
|----|------|----------|----------|------|------|
| D-P01 | プレビュー | 操作帯以外の全域 | はい | ピンチでズーム | 操作帯とは重ねない |
| D-B01 | 操作帯 | 縦: 下 / 横: 右 | はい | なし | スタジアム形 (平行線 + 半円)、半透明ダーク面 |
| D-H01 | 状態・解像度・FPS | 左上 | はい | なし | 小さい補助情報として表示 |
| D-H02 | 経過時間 | 左上2行目 | 配信開始後 | なし | 統計・電池と同じ行に表示 |
| D-H03 | 送信ビットレート | 左上2行目 | 取得後 | なし | 経過時間・電池と同じ行に表示 |
| D-H04 | 電池 | 左上2行目 | 取得成功時 | なし | 経過時間・統計と同じ行に表示 |
| D-C01 | 配信開始・停止 | 操作帯中央 | はい | 開始・停止 | 52dp丸ボタン (マイクと同サイズ) |
| D-C02 | カメラ・倍率 | 操作帯先頭 | はい | 選択 | `BACK・1x`形式のピル型ボタン |
| D-C03 | マイク | 操作帯末尾 | はい | ミュート | 52dp丸ボタン＋ON/OFFラベル |
| D-C04 | ライト | なし | いいえ | なし | 機能を削除 |
| D-C05 | 配信方向 | 設定画面のみ | いいえ | 縦横選択 | 配信画面から削除 |
| D-C06 | 設定 | 右上 | はい | 設定画面を開く | 52dp丸ボタン |
| D-M01 | 音量メーター | 左下 | はい | なし | 10セグメント。下端に沿わせる |
| D-M02 | ズーム倍率 | D-C02に統合 | はい | 選択 | 内部方式を表示しない |

高さ400dp未満では各丸ボタンを縮小し、マイク・配信ボタンの補助ラベルを隠す。

## 4. 横画面ワイヤーフレーム

横画面は右に縦長の操作帯を置き、その左側をプレビューにする。

```text
+----------------------------------------+---------+
| D-H01 状態/解像度/FPS       D-C06 設定 |  (   )  |
|                                        | D-C02   |
|               D-P01                    | D-C01 ● |
|                                        | D-C03 ○ |
| D-M01 音量                             |  (   )  |
+----------------------------------------+---------+
                                           D-B01

左の枠がD-P01のカメラプレビュー、右の縦長がD-B01の操作帯。
```

決定事項:

- 縦画面と同じ部品を右の縦長の操作帯へ並べる。プレビューとは重ねない: 決定
- 操作側は右、音量メーターは左: 現在の実装
- 端末を反対向きに回した場合: 未定
- 配信方向の選択に合わせて画面を縦または横へ固定する: 決定

## 5. 配信開始・停止

| 項目 | 候補 | 決定 |
|------|------|------|
| 形 | 円形 / 角丸長方形 / その他 | 円形 |
| 位置 | 下中央 / 右下 / 右端 / その他 | 操作帯の中央 (縦: 下帯の中央、横: 右帯の中央) |
| 大きさ | 大きな主ボタン / 他と同サイズ | マイクと同じ52dp。色で主操作を示す |
| 開始色 | 赤 / 緑 / 白 / その他 | 現状の開始色を維持 |
| 停止色 | 赤 / その他 | 現状の停止色を維持 |
| ラベル | アイコンのみ / 文字併用 | 文字併用 |
| 停止確認 | なし / タップ確認 / 長押し | 未定 |

ボタン色と表示内容を見れば、待機中か配信処理中か判断できるようにする。
大きな`待機中`・`LIVE`・`切断`バッジは置かない。状態の意味は次を維持する。

- 開始ボタンを押した直後は`接続中`であり、まだLIVEではない。
- 接続成功後だけ`LIVE`と表示する。
- 再接続中はLIVE表示にしないが、停止操作は常に残す。

## 5.1 マイク

- ON/OFFとも丸いボタンにする。
- アイコンと色の変化で状態を示す。
- 配信開始・停止ボタンと同じ大きさで操作帯に並べ、色 (緑/赤 と 暗色/赤) で区別する。

## 6. カメラ・レンズ・ズーム

| 項目 | 候補 | 決定 |
|------|------|------|
| カメラ面 | 前後トグル / 前面・背面を直接選択 | `FRONT` / `BACK`を直接選択 |
| 背面レンズ | ボトムシート / 画面上に倍率・画角ボタン | ピル型ボタンから2行ポップアップを開く |
| 表記 | `BACK 71°` / `1x`相当 / カメラ名 | 閉じた状態は`BACK・1x`、展開時はカメラ面と倍率を別行表示 |
| ズーム | なし / ピンチ / スライダー / プリセット | ピンチを採用 |
| フォーカス | 現状の自動のみ / タップフォーカス | 未定 |

端末メーカーが外部アプリへ公開したカメラだけを使い、標準画角を`1x`として利用可能なレンズを倍率へ正規化する。
同じ実レンズ・倍率になる重複IDは1つへまとめる。Android 11以降の論理マルチカメラ対応端末では
連続倍率によるレンズ切替を優先し、それ以外では物理レンズ固定とデジタルズームへフォールバックする。
この内部方式と`自動`表記は通常UIへ露出せず、デバッグ用の切替・診断だけ設定画面へ置く。

## 7. 常時表示する情報

全面プレビュー化前の配置に対して、各情報の扱いを次のように決定した。

| 情報 | 変更前 | 決定 |
|------|--------|------|
| LIVE/接続状態 | ヘッダー | 大きなバッジを削除。解像度・FPSと同じ小さな文字 |
| 経過時間 | 左上2行目 | 配信開始後に小さく表示 |
| 送信ビットレート・品質 | 左上2行目 | 取得後に小さく表示 |
| 解像度 | 左上1行目 | 小さなオーバーレイ情報として表示 |
| FPS | 左上1行目 | 小さなオーバーレイ情報として表示 |
| 電池残量 | 左上2行目 | 小さなオーバーレイ情報として表示 |
| 音量メーター | 左下 (下端に沿わせる) | 常時表示 |
| 使用マイク | (新規) | メーター直下に推定種別を小さく表示。選択UIは持たない (2026-09-13) |
| 縦/横ラベル | プレビュー左上 | 配信画面から削除。設定画面だけで選択 |
| 接続失敗理由 | 左上1行目 | 小さい状態文として表示 |

## 10. 変更指示欄

この欄へ会話で受けた修正を蓄積する。部品IDは [現在のUI仕様](current.md) または本書のIDを使う。

### 2026-09-12 (反映済み)

- 設定画面をカテゴリ階層 (メニュー → 配信 / 映像 / カメラ / 権限) にする。
- ビットレートはスライダーではなく数値入力にし、`<input type="number">` のような ∧/∨ ボタンを右端に縦に置く。
  範囲は 100〜10000 kbps。上限・下限の説明文は出さない。
- 解像度ラベルは `HD (720p) / 720 x 1280` のように一般名を併記する。`省データ (360p)` を追加する。
- フレームレートを設定できるようにする (15 / 24 / 30 / 60)。
- 接続先を複数保持し切り替えられるようにする。プリセットは PeerCast Gateway と Twitch
  (ツイキャス・自宅PeerCastStation は不要)。「Gateway」ではなく正式名「PeerCast Gateway」を使う。
- 音量メーターは配信前でも動かす。位置はプレビューの左下に沿わせる。
- 操作が画面に散らばる印象を解消する: マイクを配信開始と同じ下側に移し、配信開始をマイクと同サイズにする。
  下部の操作を陸上トラックのような平行線 + 半円の帯 (スタジアム形) にまとめ、プレビューと重ねない。
- 縦持ちで配信開始ボタンを帯の真ん中に配置する。

### 2026-09-13 (反映済み)

- 映像ページにエンコーダ選択 (互換 (ソフトウェア) / 標準 (ハードウェア)) を追加する。既定は互換。
  選択フォームはズーム方式と同じ縦並びのラジオ形式にする。
- 権限ページの「接続の準備」(PeerCast Gateway / Twitch の案内) を削除し、ページ名を「権限」にする。
- 音量メーターの下に、使用中と推定されるマイク種別を小さく表示する。選択機能は付けない。

### 2026-09-07 (反映済み)

- 配信画面はカメラプレビューを全面表示する。
- 操作パネルはプレビューの下や右に別領域として置かず、プレビュー上へオーバーレイする。
- IRL Pro、Moblin、その他の配信・標準カメラアプリのように、操作と情報を画面周辺へ寄せる。
- 現在の分割レイアウトは意図と異なるため、次期実装では使用しない。
- 大きな`切断`・`待機中`・`LIVE`ステータス表示は不要。
- 状態は`720 x 1280 / 30 fps`等と同じ小さな文字でプレビュー上に表示する。
- 配信開始・停止は、現状の色による区別を維持した丸ボタンにする。
- マイクON/OFFも丸ボタンにする。
- 縦配信・横配信の選択は設定画面だけに置き、配信画面から削除する。
- ライト機能は不要なため、UIと配信Controllerから削除する。
- カメラアイコンの丸ボタンは削除し、配信ボタン上に`BACK・1x`形式のピル型セレクターを置く。
- セレクターのポップアップは`CAMERA`と`ZOOM`の2行構成にし、通常UIには`自動`を表示しない。
