# 現状UI仕様

- 更新日: 2026-09-08
- 対象: 全面プレビュー、オーバーレイUI、カメラ・倍率セレクター実装後の現在の作業ツリー
- 根拠: Compose実装の静的確認。実機スクリーンショットからの採寸ではない

振る舞いの正本は [製品仕様](../product/spec.md)、設計判断は [UI設計](design.md)、
参考アプリの調査結果は [UI参考調査](references.md) を参照する。

## 1. 画面構成

画面は次の2画面と1つのポップアップで構成する。

| ID | 画面 | 実装 | 概要 |
|----|------|------|------|
| S-01 | 配信画面 | `ui/StreamScreen.kt` | 全面プレビュー、オーバーレイ情報・操作、配信開始・停止 |
| S-02 | 設定画面 | `ui/SettingsScreen.kt` | 配信先、配信方向、映像、権限・接続準備 |
| S-03 | カメラ・倍率ポップアップ | `CameraZoomSelector` | `FRONT` / `BACK`と倍率の選択 |

`ui/AppRoot.kt`がS-01とS-02を切り替える。画面方向の変更でActivityが再生成されても、
`showSettings`は`rememberSaveable`により保持する。

## 2. 共通の見た目

| ID | 項目 | 現状 |
|----|------|------|
| V-01 | 基調色 | 黒・ダークグレー。カメラ映像を画面全体の背景にする |
| V-02 | 開始色 | 緑 `#2E7D4F` |
| V-03 | 停止・ミュート色 | 赤系 `#B43832` / `#D1433E` |
| V-04 | 操作形状 | 配信・設定・マイクは円形、カメラ・倍率はピル型セレクターにする |
| V-05 | 情報背景 | 半透明の黒と6dp角丸。映像上でも文字を読めるようにする |
| V-06 | 安全領域 | オーバーレイ操作へ`safeDrawingPadding()`を適用する |
| V-07 | テーマ | `AppRoot`内のMaterial 3ダークカラースキーム |

## 3. 配信画面 S-01

### 3.1 構造

`SurfaceView`を画面全体へ配置し、情報と操作をその上へ重ねる。縦横とも固定のヘッダー、
下部パネル、右パネルを作らない。

```text
+--------------------------------------------------+
| I-01 状態 / 解像度 / FPS             C-04 設定   |
| I-02 時間 / 統計 / 電池                          |
|                                                  |
| M-01 音量                              C-03 マイク |
|                                                  |
|                 C-02 BACK・1x                    |
|                 C-01 開始・停止                  |
+--------------------------------------------------+

枠全体がP-01のカメラプレビュー。
```

### 3.2 情報表示

| ID | 要素 | 現状の表示・動作 |
|----|------|------------------|
| P-01 | カメラプレビュー | 黒背景の画面全体を使う。`AspectRatioMode.Adjust`を使用 |
| I-01 | 状態・映像情報 | 左上に`状態 / 720 x 1280 / 30 fps`等を小さい1行で表示 |
| I-02 | 配信詳細 | 経過時間、送信統計、電池残量を小さい1行で表示。情報がない項目は省略 |
| M-01 | 音量メーター | 左端中央に縦10セグメント。下から緑5・黄3・赤2。ミュート時は消灯 |
| I-03 | カメラ・倍率 | 下中央の配信ボタン上に`BACK・1x`形式で現在値を表示。内部のレンズ方式は表示しない |
| P-02 | 準備中表示 | 中央に`プレビュー準備中`。必須権限がなければ権限要求ボタンも表示 |

状態は大きなバッジにせず、解像度やFPSと同じ補助情報として表示する。I-01とI-02は
最大幅320dpの半透明背景に置き、長い状態や統計は1行で省略する。電池は30秒ごと、
経過時間は1秒ごと、音量は100msごとに更新する。

### 3.3 操作

| ID | 要素 | 現状の表示・動作 |
|----|------|------------------|
| C-01 | 配信開始・停止 | 下中央の82dp円形ボタン。開始は緑、停止は赤。アイコンと文字を併用 |
| C-02 | カメラ・倍率 | 下中央のピル型ボタン。S-03を開く |
| C-03 | マイク | 右端中央の52dp円形ボタン。ON/OFFラベルを表示し、ミュート時は赤 |
| C-04 | 設定 | 右上の52dp円形歯車ボタン。S-02を開く |

- 高さ400dp未満ではC-01を68dp、C-03〜C-04を44dpへ縮小し、C-01とC-03の補助ラベルを隠す。
- プレビュー準備前は配信開始とカメラ操作を無効にする。
- 接続中・再接続中もC-01は赤い停止ボタンとして操作できる。
- 配信方向の選択はS-02だけに置き、S-01には表示しない。
- プレビューを2本指でピンチすると、端末の対応範囲内で倍率を連続変更する。
- 対応する論理背面カメラを起動時に優先し、非対応端末では倍率に対応する物理レンズへ固定する。方式の差はUIへ出さない。
- ライト機能は持たない。
- 不正URLはI-01の状態欄に表示する。

### 3.4 状態ごとの差分

| 状態 | I-01 | I-02 | C-01 |
|------|------|------|------|
| 待機中 | `待機中`または`切断` | 電池 | 緑・開始 |
| 接続中 | `接続中...` | 電池 | 赤・停止 |
| LIVE | `LIVE` | 経過時間・統計・電池 | 赤・停止 |
| 再接続中 | 再接続理由 | 経過時間・電池 | 赤・停止 |
| 失敗後 | 失敗理由 | 電池 | 緑・開始 |
| 権限なし | 準備中案内 | 電池 | 無効 |

## 4. カメラ・倍率ポップアップ S-03

配信画面のC-02をアンカーとして開くMaterial 3ポップアップ。プレビューや他のUIは移動させない。

| ID | 要素 | 現状の表示・動作 |
|----|------|------------------|
| L-01 | CAMERA行 | `FRONT`と`BACK`を直接選択 |
| L-02 | ZOOM行 | `0.6x`、`1x`、`3x`等、端末で利用可能な倍率を表示 |
| L-03 | 選択表示 | 選択中のカメラ面・倍率を色と太字で表示 |
| L-04 | 閉じる操作 | パネル外タップで閉じる |

倍率は標準画角を`1x`として物理レンズの画角から算出する。同じ倍率になる重複カメラIDは1項目へ統合する。
対応端末では論理カメラへ倍率を渡し、非対応端末では対応する物理レンズを内部で選択する。
前面カメラは利用可能なデジタル倍率をプリセット表示する。`自動`や物理カメラIDは通常UIへ表示しない。

## 5. 設定画面 S-02

通常機能に加え、デバッグ可能なAPKだけカメラ診断を表示する。

| セクション | 内容 |
|------------|------|
| ヘッダー | 戻る、`配信設定`、自動保存案内 |
| 配信先 | RTMPサーバーURL、ストリームキー、Gateway・自宅Stationプリセット |
| 映像 | 縦横選択、解像度、ビットレート、固定エンコード情報 |
| カメラ診断 | デバッグAPKのみ。ズーム方式の強制切替とAPI・カメラID・倍率範囲 |
| 権限と接続準備 | 権限要求、Gateway・自宅Stationの説明 |

- 内容の最大幅は720dpで、画面全体を縦スクロールできる。
- 配信方向は設定画面だけで選択する。配信処理中は変更できない。
- 配信処理中はビットレート以外を変更できない。ビットレートは即時反映する。
- 方向切替によるActivity再生成後も設定画面に留まる。

## 6. 未検証事項

この文書は静的確認に基づく。Android Studioと実機で次を確認する必要がある。

- 縦横画面でプレビューが意図した比率・向きになり、操作が安全領域内に収まること。
- 横画面や大きなフォントでも、情報・カメラ倍率セレクター・マイク・配信ボタンが重ならないこと。
- プレビュー準備中、接続中、LIVE、再接続中、失敗時の表示と操作可否。
- カメラ・レンズ選択、マイク状態、設定画面往復、Activity再生成後の状態保持。
