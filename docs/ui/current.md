# 現状UI仕様

- 更新日: 2026-09-08
- 対象: プレビュー領域 + 操作帯、オーバーレイ情報、カメラ・倍率セレクター実装後の現在の作業ツリー
- 根拠: Compose実装の静的確認。実機スクリーンショットからの採寸ではない

振る舞いの正本は [製品仕様](../product/spec.md)、設計判断は [UI設計](design.md)、

## 1. 画面構成

画面は次の2画面と1つのポップアップで構成する。

| ID | 画面 | 実装 | 概要 |
|----|------|------|------|
| S-01 | 配信画面 | `ui/StreamScreen.kt` | プレビュー領域 + スタジアム形の操作帯、オーバーレイ情報 |
| S-02 | 設定画面 | `ui/SettingsScreen.kt` | カテゴリメニュー → 配信 / 映像 / カメラ / 権限と接続 |
| S-03 | カメラ・倍率ポップアップ | `CameraZoomSelector` | `FRONT` / `BACK`と倍率の選択 |

`ui/AppRoot.kt`がS-01とS-02を切り替える。画面方向の変更でActivityが再生成されても、
`showSettings`は`rememberSaveable`により保持する。

## 2. 共通の見た目

| ID | 項目 | 現状 |
|----|------|------|
| V-01 | 基調色 | 黒・ダークグレー。カメラ映像をプレビュー領域の背景にし、操作帯は半透明ダーク面 |
| V-02 | 開始色 | 緑 `#2E7D4F` |
| V-03 | 停止・ミュート色 | 赤系 `#B43832` / `#D1433E` |

## 3. 配信画面 S-01

### 3.1 構造

プレビュー領域 (P-01) と操作帯 (B-01) を分け、重ねない。情報表示・設定・音量メーターだけをP-01へ重ねる。
縦配信 (縦持ち) ではB-01を下に横長、横配信 (横持ち) では右に縦長で置く。

```text
縦
+--------------------------------------------------+
| I-01 状態 / 解像度 / FPS             C-04 設定   |
| I-02 時間 / 統計 / 電池                          |
|                                                  |
|                   P-01                           |
|                                                  |
| M-01 音量                                        |
+--------------------------------------------------+
| (  C-02 BACK・1x    C-01 開始    C-03 マイク  )  |  B-01
+--------------------------------------------------+

横
+-----------------------------------------+--------+
| I-01 / I-02                   C-04 設定 |  ( )   |
|                                         | C-02   |
|                 P-01                    | C-01   |
|                                         | C-03   |
| M-01 音量                               |  ( )   |
+-----------------------------------------+--------+
                                            B-01
```

### 3.2 情報表示

| ID | 要素 | 現状の表示・動作 |
|----|------|------------------|
| P-01 | カメラプレビュー | 操作帯を除いた領域を使う。`AspectRatioMode.Adjust`で比率を維持 |
| B-01 | 操作帯 | スタジアム形 (`CircleShape`) の半透明ダーク面 + 1dp の薄い縁。帯を3等分したスロットに C-02・C-01・C-03 を置き、C-01 が帯の中心に来る |
| I-01 | 状態・映像情報 | 左上に`状態 / 720 x 1280 / 30 fps`等を小さい1行で表示 |
| I-02 | 配信詳細 | 経過時間、送信統計、電池残量を小さい1行で表示。情報がない項目は省略 |
| M-01 | 音量メーター | 左下に縦10セグメント (下端に沿わせる)。下から緑5・黄3・赤2。ミュート時は消灯。配信前のプレビュー中も動く |
| I-03 | カメラ・倍率 | 操作帯のC-02に`BACK・1x`形式で現在値を表示。内部のレンズ方式は表示しない |
| P-02 | 準備中表示 | 中央に`プレビュー準備中`。必須権限がなければ権限要求ボタンも表示 |

状態は大きなバッジにせず、解像度やFPSと同じ補助情報として表示する。I-01とI-02は
最大幅320dpの半透明背景に置き、長い状態や統計は1行で省略する。電池は30秒ごと、
経過時間は1秒ごと、音量は100msごとに更新する。

### 3.3 操作

| ID | 要素 | 現状の表示・動作 |
|----|------|------------------|
| C-01 | 配信開始・停止 | 操作帯中央の52dp円形ボタン (マイクと同サイズ)。開始は緑、停止は赤。アイコン + ラベル |
| C-02 | カメラ・倍率 | 操作帯先頭のピル型ボタン。S-03を開く |
| C-03 | マイク | 操作帯末尾の52dp円形ボタン。ON/OFFラベルを表示し、ミュート時は赤 |
| C-04 | 設定 | プレビュー右上の52dp円形歯車ボタン。S-02を開く |

- 高さ400dp未満ではC-01・C-03・C-04を44dpへ縮小し、C-01とC-03の補助ラベルを隠す。
- プレビュー準備前は配信開始とカメラ操作を無効にする。
- 接続中・再接続中もC-01は赤い停止ボタンとして操作できる。
- 配信方向の選択はS-02だけに置き、S-01には表示しない。
- プレビューを2本指でピンチすると、端末の対応範囲内で倍率を連続変更する。
- 対応する論理背面カメラを起動時に優先し、非対応端末では倍率に対応する物理レンズへ固定する。方式の差はUIへ出さない。
- ライト機能は持たない。
- 不正URLはI-01の状態欄に表示する。

### 3.4 状態ごとの差分

| 状態 | I-01 | I-02 | C-01 |
|------|------|------|------|
| 待機中 | `待機中`または`切断` | 電池 | 緑・開始 |
| 接続中 | `接続中...` | 電池 | 赤・停止 |
| LIVE | `LIVE` | 経過時間・統計・電池 | 赤・停止 |
| 再接続中 | 再接続理由 | 経過時間・電池 | 赤・停止 |
| 失敗後 | 失敗理由 | 電池 | 緑・開始 |
| 権限なし | 準備中案内 | 電池 | 無効 |

## 4. カメラ・倍率ポップアップ S-03

配信画面のC-02をアンカーとして開くMaterial 3ポップアップ。プレビューや他のUIは移動させない。

| ID | 要素 | 現状の表示・動作 |
|----|------|------------------|
| L-01 | CAMERA行 | `FRONT`と`BACK`を直接選択 |
| L-02 | ZOOM行 | `0.6x`、`1x`、`3x`等、端末で利用可能な倍率を表示 |
| L-03 | 選択表示 | 選択中のカメラ面・倍率を色と太字で表示 |
| L-04 | 閉じる操作 | パネル外タップで閉じる |

倍率は標準画角を`1x`として物理レンズの画角から算出する。同じ倍率になる重複カメラIDは1項目へ統合する。
対応端末では論理カメラへ倍率を渡し、非対応端末では対応する物理レンズを内部で選択する。
前面カメラは利用可能なデジタル倍率をプリセット表示する。`自動`や物理カメラIDは通常UIへ表示しない。

## 5. 設定画面 S-02

カテゴリメニューから各ページへ1階層掘る構成。デバッグ可能なAPKだけ `カメラ` を表示する。

| 画面 | 内容 |
|------|------|
| ヘッダー | 戻る、ページ名 (メニューでは `設定`)、補足文 |
| メニュー | `配信` `映像` `カメラ` `権限と接続` の行。アイコン、現在値の要約、右向き矢印 |
| 配信 | 接続先一覧 (選択・編集)、追加ボタン (PeerCast Gateway / Twitch / 空の接続先)。編集は3階層目 (名前・URL・キー・削除) |
| 映像 | 縦横選択、解像度、フレームレート (セグメント選択)、ビットレート (数値入力 + ∧/∨ ボタン)、固定エンコード情報 |
| カメラ | デバッグAPKのみ。ズーム方式の強制切替とAPI・カメラID・倍率範囲 |
| 権限と接続 | 権限要求、PeerCast Gateway・Twitchの説明 |

- 内容の最大幅は720dpで、各画面を縦スクロールできる。
- 戻るボタン・端末の戻るは接続先の編集 → ページ → メニュー → 配信画面の順に戻る。
- 配信方向は設定画面だけで選択する。配信処理中は変更できない。
- 配信処理中はビットレート以外を変更できない。ビットレートは即時反映する。
- 方向切替によるActivity再生成後も設定画面と選択中のページに留まる。

## 6. 未検証事項

この文書は静的確認に基づく。Android Studioと実機で次を確認する必要がある。

- 縦横画面でプレビューが意図した比率・向きになり、操作が安全領域内に収まること。
- 横画面や大きなフォントでも、情報・カメラ倍率セレクター・マイク・配信ボタンが重ならないこと。
- プレビュー準備中、接続中、LIVE、再接続中、失敗時の表示と操作可否。
- カメラ・レンズ選択、マイク状態、設定画面往復、Activity再生成後の状態保持。
